# Netflix Data Analysis using Microsoft Excel

## Overview
This project presents an exploratory analysis of the Netflix Titles dataset using Microsoft Excel. The objective is to analyze content trends, distribution, and key business insights through data cleaning, pivot tables, and an interactive dashboard.

## Objectives
- Analyze the distribution of Movies and TV Shows.
- Examine content trends over the years.
- Identify the top contributing countries.
- Explore genre and rating distributions.
- Build an interactive dashboard for data-driven insights.

## Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- Data Cleaning

## Dataset
- Source: Netflix Titles Dataset (Kaggle)

## Dashboard Features
- Total Movies & TV Shows
- Content by Country
- Content by Genre
- Rating Distribution
- Release Year Analysis
- Interactive Filters (Slicers)

## Key Insights
- Movies constitute the majority of Netflix's content library.
- Content production has increased significantly in recent years.
- A small number of countries contribute a large share of available titles.
- Drama and International Movies are among the most represented genres.
